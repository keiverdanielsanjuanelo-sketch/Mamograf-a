# Sitio web educativo: Mamografía + IA

## Abrir en Visual Studio Code
1. Descomprime `mamografia_vscode.zip`.
2. Abre la carpeta `mamografia_vscode` en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes instalar la extensión **Live Server** y pulsar **Go Live** para previsualizar los cambios.

## Personalizar
- Edita los textos en `index.html`.
- Cambia colores, tipografías y diseño en `styles.css`.
- `script.js` controla el menú adaptable para móviles.
- En la sección “Presentación del grupo”, reemplaza los campos de ejemplo por los datos reales.

## Publicar para obtener un enlace público
Este proyecto funciona localmente, pero para que otras personas puedan entrar desde cualquier dispositivo debes publicarlo en un servicio de alojamiento. Una opción gratuita es GitHub Pages:
1. Crea una cuenta en GitHub y un repositorio nuevo.
2. Sube `index.html`, `styles.css` y `script.js` (o todo el contenido de la carpeta).
3. En el repositorio, abre **Settings → Pages**.
4. En “Build and deployment”, elige la rama principal y la carpeta raíz, y guarda.
5. GitHub generará una URL pública para compartir. La URL estará disponible después de que termine la publicación.
